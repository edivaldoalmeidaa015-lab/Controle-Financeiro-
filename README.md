# Meu Controle Financeiro

Aplicativo financeiro pessoal instalável no Android, com funcionamento offline e dados armazenados somente no aparelho.

## Recursos

- receitas e despesas;
- cartões e compras parceladas;
- contas a pagar;
- metas e orçamento mensal;
- painel com gráficos;
- importação de extratos OFX e CSV do Inter, Mercado Pago, Santander e Caju Alimentação;
- prevenção de lançamentos duplicados;
- backup e restauração dos dados.

## Publicação no GitHub Pages

Esta edição foi preparada sem subpastas para facilitar o envio pelo navegador. Todos os arquivos devem ser colocados diretamente na raiz do repositório.

Os dados financeiros não são enviados ao GitHub. Eles permanecem no armazenamento local do navegador em que o aplicativo é utilizado.
